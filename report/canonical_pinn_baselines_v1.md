# 经典 PINN 基线与 DKAN–有限体积混合模型对照

协议：`canonical_pinn_baselines_v1`  
日期：2026-07-16

## 比较范围

该表使用 5 个冻结种子、float64 和完全相同的 MLP 参数量，对普通 MLP-PINN、GW-PINN、AV-PINN 与 CI-PINN进行经典单问题比较。Burgers 使用振幅 1、均值 0.2 的无黏正弦初值，在 `t=0.6` 对 4096 网格 WENO；Euler 使用标准 Sod 管，在 `t=0.2` 对精确 Riemann 解。

混合模型行使用已冻结的 v3 结构，但这些经典状态不是新的 v3 盲测，所以本表只作描述性对照，不并入强 20% 统计。

## 守恒与熵的取舍

- Burgers AV-PINN 虽然状态误差在 PINN 中最低，但控制体积平衡 RMSE 中位数为 0.7582，高于普通 MLP-PINN 的 0.4781；人工粘性改善剖面不等于改善原方程守恒残差。
- 原始 DKAN-PINN 相比 MLP 明显降低状态误差，但 Burgers 最大质量漂移中位数仍为 `7.76e-3`，高于 MLP 的 `1.90e-3`；仅替换网络并未自动带来守恒性。
- Burgers CI-PINN 的最大质量漂移中位数为 `1.01e-3`，优于普通 MLP-PINN 的 `1.90e-3`，但状态 L2 退化到 0.2880。
- Euler CI-PINN 的能量平衡误差中位数为 0.0242、熵违反中位数为 0.00503，均优于普通 MLP-PINN 的 0.0919 与 0.0201；其状态复合 L2 仍较差。
- 混合模型的子单元重构按构造保持每个有限体积单元平均量，v3 最大变化为 `4.44e-16`；这与 PINN 的近似全局守恒不是同一强度的保证。

PINN 训练成本是每个经典问题一次；混合模型预训练覆盖参数化问题族，可跨工况复用，但在线仍需有限体积推进。二者不能只比较推理前向时间。单次实测的 Burgers WENO-4096 参考求解为 3.62 s，Euler 1600 点精确采样为 0.00164 s；这些仅用于环境内量级参考。

## 结论边界

1. 原始 DKAN-PINN 优于同预算 MLP 系列：Burgers 与 AV-PINN 接近，Euler 明显更好；但仍平滑激波且不具硬守恒。
2. 在四种 MLP 架构 PINN 中，AV-PINN 的状态误差最低；CI-PINN 展示了守恒/熵改善与状态误差之间的冲突。
3. 固定有限体积方法已经显著优于连续 PINN；DKAN 子单元混合进一步改善连续剖面。
4. 成功方法仍是监督式有限体积混合模型，不是纯 DKAN-PINN。
