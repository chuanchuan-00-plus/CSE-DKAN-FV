# CSE-DKAN-PINN 创新与否证日志

更新日期：2026-07-15  
状态：开发实验；所有结果均为单种子 float32 先导结果，不构成“综合提升 20%”论文结论。

## 当前可复现实装

- WENO5-Z + SSP-RK3 周期 Burgers 参考解；激波前解析特征线收敛检查通过。
- Sod/Lax 精确理想气体 Riemann 解。
- 参数量匹配的 MLP（8,641 参数）与 KAF-DKAN（8,562 参数）。
- 强形式、弱控制体积、二次熵、全局守恒、RH、Lax/压缩性约束。
- 双层激波课程：先用特征线相交与 RH 预训练流形，再冻结流形训练场解。
- 当前主模型 `ConservativeSpectralShockBurgersAnsatz`：时间 DKAN 生成零均值 Fourier 系数；显式 sawtooth–sigmoid 跳变基解析零均值且周期端点一致，因此质量守恒是结构性质。

当前测试：20 项全部通过，包括 WENO 光滑区收敛、Sod 星区状态、DKAN 梯度、CV/RH 解析一致性、参数预算，以及随机参数下 CSE 结构质量守恒。

## 目前能下的结论

以同为 500 步的 DKAN（L2 0.2180、宽度 0.1152、CV 0.4600、熵 0.0129、21.53 秒）为参照，守恒谱 CSE：

- L2 下降 61.7%；
- 激波宽度下降 90.4%，位置误差降为 0；
- 最大质量漂移降至数值舍入量级；
- 但全域 CV RMSE 上升约 49.9%，熵违反均值上升约 110.6%，训练成本约为 3.02 倍。

因此它通过了“显式激波基是否有效”和“全局质量能否结构守恒”的概念验证，但未通过预注册的“任一主指标退化不超过 10%”工程门槛，也没有多种子置信区间。不能声称综合提升 20%。

## 已否证的做法

1. 只把 DKAN 接到强形式 PINN：创新性和守恒性都不足。
2. RH + 熵软约束：连续零跳幅解也可近似满足，存在退化。
3. 双专家：有效但计算冗余过大。
4. 自由 interface ridge：会产生非物理尖峰和过冲。
5. 减窄门函数时同步降低学习率：网络来不及重新平衡约束。
6. 把 CV 积分除以面积作为唯一训练残差：退化成局部强残差；小体积放大门误差。
7. 用解析全域阶跃硬加跳幅：包络区自身不满足 PDE，制造大残差。
8. 单纯提高严格 CV 权重：只在锐度和局部守恒之间移动，不能消除结构冲突。

## 下一创新门槛

下一阶段不再继续调标量损失权重，而改成局部守恒结构：以控制体积平均量为预测对象，用共享 DKAN 表示单元内部高阶矩，激波流形上使用单一数值通量同时更新左右单元；Burgers 使用 Godunov/熵稳定通量，Euler 使用 HLLC + 熵修正与正性参数化。这样局部守恒来自“同一界面通量一进一出”，而不是事后惩罚。只有该版本把独立 CV 与熵指标至少降到最强基线的 0.9 倍以内，才进入多种子 Gate 2。

## 局部守恒骨架进展

已实现 `ConservativeBurgersFV`、`DKANTVDLimiter` 与 `EulerHLLCFV`。DKAN limiter 只能缩放 TVD-MC 斜率，因此任意网络参数下仍共享单一 Godunov 界面通量；Euler HLLC 版本包含密度/压力正性审计。它们目前是下一代混合模型的保守骨架，不计作 DKAN-PINN 的最终比较结果。

- Burgers 一阶 Godunov，256 单元：L2 0.0651，宽度 0.0123，位置误差 0，质量误差 3.14e-15，0.152 秒。
- Burgers TVD-Godunov，512 单元：L2 0.0375，宽度 0.00579，质量误差 6.11e-15，0.364 秒。
- Sod HLLC，400 单元：密度 L2 0.0252，激波宽度 0.0185，位置误差 0.0025；质量、边界动量、能量平衡误差分别为 9.21e-15、2.75e-15、2.15e-14；最小密度/压力为 0.125/0.1。
- Sod HLLC，800 单元：密度 L2 0.0192，激波宽度 0.00923，位置误差 0.00125，1.43 秒。

完整可复现数据见 `results/conservative_backbone/summary.json`。下一步是让 DKAN 学习受约束的高阶重构，同时让 PINN 部分学习连续子单元表示与跨参数泛化；共享通量更新保持不变。
