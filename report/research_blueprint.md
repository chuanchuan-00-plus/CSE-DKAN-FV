# DKAN + PINN 含激波守恒律研究蓝图

> 版本：2026-07-15；输入论文：arXiv:2507.08338v2（2026-03-24）  
> 本文把“原论文事实”“外部文献事实”和“拟议方案”分开书写。拟议方案尚未经过实验验证。

## 0. 结论先行

1. **“DKAN + PINN” 已经被输入论文实现，完整模型名为 DPINN。** 原方法由自适应 Fourier 特征嵌入、DKAN、复杂几何网格变换、可学习局部人工粘性组成。因此，单纯把 DKAN 换进 MLP-PINN 不足以构成新课题。
2. **推荐的新模型主线是 CSE-DKAN-PINN**（Conservative, Shock-Explicit and Entropy-stable DKAN-PINN）：把 DKAN 的陡峭基函数变成可定位的激波流形，在平滑区使用强形式、跨间断使用时空控制体积弱形式，并在流形上施加 Rankine-Hugoniot（RH）跳跃条件和熵条件。
3. **最有价值的改进不是继续堆网络组件，而是修复原 DPINN 的两个结构性短板：**强形式残差在间断处不合适；局部人工粘性依赖问题特定的激波传感器。拟议方法用弱形式守恒和熵残差传感器替代这两处薄弱环节。
4. **“综合提升 20%”必须预注册。** 推荐用跨任务、跨随机种子的加权几何综合增益，比较对象是最强神经基线；WENO 是参考解与传统求解器基准，不宜被混入同一个“神经方法提升”分母。
5. **应先做 1D 闭环，再上 2D。** 先在无黏/黏性 Burgers、Sod、Lax、Shu-Osher 上证明守恒、熵、分辨率和稳定性，再做四象限 2D Riemann；双马赫反射和前向台阶属于二维激波相互作用/几何基准，并非严格意义上的 2D Riemann 问题。

## 1. 输入论文给出的事实边界

### 1.1 原 DPINN 已包含什么

- 自适应 Fourier 特征嵌入（KAF）：低频 GELU 通道与可学习 Fourier 高频通道共同输入网络，见原文 p.4-5 S014-S019。
- DKAN：每条可学习一元函数由 Dynamic Tanh（DyT）与 B-spline 基组成，原文写为
  \(
  \psi(x)=w_t\tanh(w_a(x-w_b))+w_s\sum_i w_{c_i}S_i(x)
  \)，见 p.6-7 S020-S023。
- 网格变换：把复杂物理域映射到均匀计算域，见 p.7-8 S024-S027。
- 可学习局部人工粘性：\(\mu=w_\nu r(x)s(x)\)，其中谱半径控制尺度、传感器控制作用区域，见 p.8-9 S028-S033。

## 2. 拟议模型：CSE-DKAN-PINN

### 2.1 建模思想

原 DKAN 的有限斜率 tanh 仍是连续函数，只能近似间断。拟议模型把陡峭基从“隐藏层边上的不可定位激活”提升为“输入时空中的可定位激波流形”。

令 \(z=\mathrm{KAF}(x,t,\lambda)\)，\(\lambda\) 是黏度、压力比或马赫数等参数；预测原始变量的潜变量为

\[
V_\theta(x,t,\lambda)
=V_s(z)+\sum_{j=1}^{J} A_j(z)H_{\kappa_j}(\phi_j(x,t,\lambda)),
\qquad
H_\kappa(\phi)=\tfrac12[1+\tanh(\kappa\phi)].
\]

- \(V_s\)：平滑 KAN/DKAN 主干，表示稀疏波和平滑背景。
- \(A_j\)：第 \(j\) 个跳跃幅值网络。
- \(\phi_j=0\)：可学习间断流形；1D 中是激波/接触间断轨迹，2D 中是曲线或曲面。
- \(\kappa_j\)：从小到大退火，训练早期平滑、后期锐化。
- \(J\)：设上限并加组稀疏正则，允许不需要的间断基自动关闭。

Euler 输出建议使用 \(V=(\log\rho,u,\log p)\)，通过指数或带下界的 softplus 保证 \(\rho,p>0\)，再转换为守恒变量 \(U=(\rho,\rho u,E)\)。

### 2.2 混合强/弱物理约束

平滑区保留强形式以获得高阶精度；间断附近和全局守恒使用时空控制体积。对随机时空控制体积 \(C\)，定义

\[
\mathcal L_{cv}
=\frac1{N_C}\sum_C
\left\|
\int_{\partial C}(n_t U+n_x F)\,\mathrm dS
-\int_C S\,\mathrm dV
\right\|_2^2/|C|^2.
\]

黏性 Burgers 使用总通量 \(F_\nu(u,u_x)=u^2/2-\nu u_x\)，不能把物理黏性与人工黏性混为一谈。

流形 \(\phi_j=0\) 上直接约束分布意义下的 RH 条件：

\[
\mathcal L_{RH}
=\frac1{N_\Gamma}\sum_{j,k}
\left\|n_t[U]+n_x[F(U)]\right\|_2^2.
\]

在 1D 中，这等价于 \([F]-s[U]=0\)，其中 \(s=-\phi_t/\phi_x\)。左右状态从流形法向两侧的小偏移点取得，并对偏移尺度做敏感性检查。

### 2.3 熵稳定与守恒

对凸数学熵对 \((\eta,q)\)，无黏守恒律满足
\(\partial_t\eta+\partial_xq\le0\)。控制体积熵损失为

\[
\mathcal L_{ent}
=\frac1{N_C}\sum_C
\operatorname{ReLU}\!\left(
\int_{\partial C}(n_t\eta+n_xq)\,\mathrm dS
\right)^2.
\]

- Burgers 可取 \(\eta=u^2/2, q=u^3/3\)。
- Euler 建议使用凸数学熵而不是直接混用“物理熵增”的相反符号；作图时再转换为物理比熵 \(s=\log(p/\rho^\gamma)\)。
- 黏性 Burgers 应检查包含 \(\nu u_x^2\) 耗散项的熵平衡，不启用无黏 RH 激波损失。

全局守恒误差带边界通量修正：

\[
e_Q(t)=
\frac{\left\|\int_\Omega U(x,t)\,dx-\int_\Omega U(x,0)\,dx
+\int_0^t[F_R-F_L],d\tau\right\|_1}
{\int_\Omega|U(x,0)|\,dx+\epsilon}.
\]

将其既作为训练损失 \(\mathcal L_G\)，也作为独立评估指标；二者使用不同的时间采样点，防止“在训练点守恒”。

### 2.4 传感器与人工粘性

原 DPINN 的压力梯度/停滞点传感器依赖具体流动。建议改为无量纲的组合传感器：

\[
s_\theta=\sigma\{k[\widehat{|r_{cv}|}+\beta\widehat{v_{ent}}-\tau]\},
\]

其中 \(r_{cv}\) 是局部控制体积守恒缺陷，\(v_{ent}\) 是熵不等式违反量，帽号表示稳健标准化。人工粘性只在早期课程学习使用：

\[
\mu_{art}=\alpha_{stage}\,\operatorname{softplus}(a_\mu)\,r(U)s_\theta,
\qquad \alpha_{stage}\downarrow0.
\]

最终 Euler 评估必须报告 \(\mu_{art}\) 是否接近零；否则模型可能只是用耗散换取稳定。

### 2.5 总损失

\[
\mathcal L=
\lambda_s\mathcal L_{strong}^{smooth}
+\lambda_{cv}\mathcal L_{cv}
+\lambda_{RH}\mathcal L_{RH}
+\lambda_{ent}\mathcal L_{ent}
+\lambda_G\mathcal L_G
+\lambda_{ic}\mathcal L_{ic}
+\lambda_{bc}\mathcal L_{bc}
+\lambda_{pos}\mathcal L_{pos}
+\lambda_{sp}\mathcal L_{sparsity}
+\lambda_\mu\mathcal L_{AV}.
\]

损失权重不能只手工调到最优结果。推荐用梯度范数平衡加梯度冲突投影，并把同一权重策略应用于所有可兼容基线；GW-PINN 的物理梯度权重仍作为独立方法保留。

## 3. 训练课程

1. **阶段 A：平滑预训练（20% 步数）**  
   小 \(\kappa\)、弱局部 AV；IC/BC、平滑区强残差和粗控制体积损失为主。
2. **阶段 B：守恒成形（35%）**  
   激活多尺度随机控制体积；逐步增加 RH 与熵损失；根据守恒/熵缺陷重采样。
3. **阶段 C：间断锐化（35%）**  
   增大 \(\kappa\)，减小人工粘性，增加流形两侧状态采样；冻结不活跃的跳跃基。
4. **阶段 D：物理解偏（10%）**  
   \(\mu_{art}\to0\)，较低学习率联合微调；用独立控制体积和时间点早停。

若阶段 B 前控制体积守恒误差不下降，停止锐化；否则可能得到“很窄但位置错误/不守恒”的伪激波。

## 4. 问题矩阵

### 4.1 必做 1D

| 问题 | 目的 | 参数扫描 | 参考解 |
|---|---|---|---|
| 无黏 Burgers，光滑正弦初值 | 真正有限时间成激波；验证 RH/熵 | 幅值、终止时间 | WENO5-Z + SSP-RK3，4096-8192 点收敛检查 |
| 黏性 Burgers，光滑正弦初值 | 奇异摄动与有限宽内层；不要称数学间断 | \(\nu=10^{-2},3\times10^{-3},10^{-3},3\times10^{-4},10^{-4}\) | Cole-Hopf（适用边界时）或高分辨率谱/WENO+中心扩散 |
| Euler Sod | 稀疏波、接触间断、激波共存 | 压力比 2, 10, 100 | 精确 Riemann 解 + WENO |
| Euler Lax | 更强激波和更快接触间断 | 标准设置 + 扰动 | 精确 Riemann 解 + WENO |
| Shu-Osher | 激波与熵波相互作用，检验过耗散 | 波幅、频率 | WENO5-Z 高分辨率 |
| 双爆轰/强激波管 | 鲁棒性、正性 | 压力比至 \(10^3\) | WENO/HLLC + 正性保护 |

“Sod 的马赫数扫描”定义并不自然。若要严格做马赫数曲线，应由给定上游 \(M_1\) 的法向激波关系构造左右状态，扫描 \(M_1=1.1,1.5,2,3,5\)。

### 4.2 可选 2D

按以下顺序递进：

1. 四象限 2D Riemann（真正的二维 Riemann 问题）；
2. 双马赫反射（移动斜激波、三重点和滑移线）；
3. 前向台阶（几何边界、反射和马赫杆）；
4. 原论文 NACA0012 跨/超声速流，用于与 DPINN 原结果接轨。

2D 不应进入第一阶段“20% 达标门槛”；先把它作为外推验证，避免在实现尚不稳定时耗尽算力。

## 5. 比较方法

### 5.1 核心基线（所有 1D）

- MLP-PINN（强形式）。
- KAN/PIKAN（无 DyT），隔离“KAN 本身”的贡献。
- **原始 DPINN**：最重要的直接基线，用户最初列表中缺少，但不能省略。
- GW-PINN + seq2seq。
- 自适应局部 AV-PINN。
- PINNs-WE（梯度加权 + RH + 全局守恒）。
- CI-PINN（Coupled Integral PINN）。
- wPINN 或 2026 WE-PINN（弱形式 + 熵）。
- WENO5-Z + SSP-RK3（高分辨率参考和单次前向求解基准）。

### 5.2 公平预算的三种视角

每个神经方法都报告三组结果：

1. 参数量匹配（±5%）；
2. GPU 秒数匹配（同硬件、同精度）；
3. 共同最大预算内的最佳验证模型。

不能只复用各论文的最优网络大小，因为原 DPINN 的优势之一正是参数少，而代价是训练/推理更慢。

## 6. 指标定义

### 6.1 状态误差

- Burgers：归一化 \(L_1,L_2,L_\infty\)。
- Euler：对 \(\rho,u,p\) 分别归一化后取宏平均，另报告守恒变量误差。
- 1D 再报告 Wasserstein-1/累积分布误差，降低“轻微错位导致点态误差爆炸”的偏置。

### 6.2 激波/接触分辨率

- 单调激波的 10%-90% 宽度 \(\delta_{10-90}=|x_{90}-x_{10}|\)。
- 梯度等效宽度 \(\delta_g=|U_R-U_L|/\max|\partial_x U|\)。
- 位置误差 \(|x_s^{pred}-x_s^{ref}|\)。
- 总变差过量 \(e_{TV}=\max(0,TV(U_{pred})-TV(U_{ref}))/TV(U_{ref})\)，惩罚 Gibbs 振荡。

黏性 Burgers 的真实层宽不为零，指标应是 \(|\delta_{pred}-\delta_{ref}|/\delta_{ref}\)，不是无条件“越窄越好”。无黏问题只有在平台值、位置和 TV 通过门槛后才比较宽度。

### 6.3 守恒与熵

- \(\max_t e_{mass}(t),\max_t e_{momentum}(t),\max_t e_{energy}(t)\)。
- 数学熵控制体积违反率：违反体积占比、平均正部和最大正部。
- Euler 压缩激波两侧物理熵差；接触间断单独标记，不把它误判为压缩激波。

### 6.4 鲁棒性和成本

- 至少 5 个种子用于开发，10 个种子用于最终 1D 主结果。
- 失败定义：NaN/Inf、\(\rho\) 或 \(p\) 非正、误差超过预设上限、守恒误差超过上限。
- 报告中位数、IQR、均值和分层 bootstrap 95% CI。
- 成本：训练 GPU 秒、峰值显存、推理时间、达到给定误差阈值的 time-to-accuracy。

## 7. “综合提升 20%”的可检验定义

令每个小指标均为“越小越好”，\(m_b\) 为该任务上最强神经基线的指标，\(m_n\) 为新模型指标：

\[
G=\exp\left[\sum_i w_i\log\frac{m_{b,i}+\epsilon_i}{m_{n,i}+\epsilon_i}\right].
\]

推荐权重：

| 维度 | 权重 |
|---|---:|
| 状态误差 | 0.30 |
| 激波/接触分辨率（含位置与 TV） | 0.20 |
| 守恒误差 | 0.15 |
| 熵违反 | 0.10 |
| 跨种子/跨参数失败率 | 0.10 |
| 训练 GPU 秒 | 0.10 |
| 推理时间 | 0.05 |

成功门槛分两级：

- **工程门槛：**跨任务中位 \(G\ge1.20\)，95% CI 下界 \(>1.0\)，任何主任务的状态误差或守恒指标不得恶化超过 10%。
- **强论文表述“至少提升 20%”：**分层 bootstrap 的 95% CI 下界也应 \(\ge1.20\)。

WENO 不作为 \(m_b\) 的分母，但单独给出误差-时间 Pareto 曲线。对单个前向问题，WENO 很可能仍显著快于 PINN；神经方法的价值应同时在参数化多查询、反问题或可微优化场景中验证。

## 8. 消融实验

以完整 CSE-DKAN-PINN 为起点，单次只去掉一个模块：

1. 去掉显式间断基，退化为 KAF+KAN/DKAN 平滑主干；
2. 去掉控制体积弱损失，仅保留强形式；
3. 去掉 RH 条件；
4. 去掉熵约束；
5. 去掉全局守恒约束；
6. 固定人工粘性，不做退火；
7. 去掉熵/守恒传感器，换回问题特定压力梯度传感器；
8. 单尺度控制体积替代多尺度控制体积；
9. 固定 \(J\) 且无稀疏正则，检验间断基冗余；
10. 去掉 Fourier 嵌入，检验其对陡峭但连续结构和 Shu-Osher 高频波的贡献。

应报告每个消融对综合分数、守恒、熵、宽度和成本的影响，而不仅是训练 loss。

## 10. 分阶段决策门

### Gate 0：复现原论文

- Burgers Table 1 关键误差在原报告的 ±15% 相对范围内；
- Sod/Lax 轮廓和激波位置定性一致；
- 若无法复现，先停止扩展，记录代码/超参数缺口。

### Gate 1：守恒弱形式 MVP

- 原 DPINN + 控制体积/全局守恒在 Burgers 与 Sod 上稳定运行；
- 守恒误差至少降低 50%，状态误差不得恶化超过 10%；
- 训练成本相对原 DPINN 不超过 1.5 倍。

### Gate 2：显式间断流形

- 激波宽度和位置同时改善；
- RH 残差与熵违反显著下降；
- 至少 90% 种子无正性/发散失败。

### Gate 3：20% 主张

- 完成全部 1D 核心任务、统一调参和最终种子；
- 达到第 7 节工程门槛后再进入 2D；
- 2D 作为外推验证，不回头用于选择 1D 超参数。

| 风险 | 诊断 | 备选方案 |
|---|---|---|
| 显式流形数量不对 | 门函数重叠、跳跃幅值塌缩 | 先固定已知拓扑；再用组稀疏和 birth/death 机制 |
| 控制体积积分噪声大 | loss 方差高、种子敏感 | Sobol 点、解析矩形边积分、多尺度但固定随机数 |
| RH 左右状态污染 | 偏移尺度变化导致残差剧变 | 多偏移尺度一致性损失，避开相邻间断 |
| 熵条件符号/定义混乱 | Burgers 与 Euler 趋势相反 | 全部训练统一用凸数学熵；物理熵仅作解释图 |
| 过度人工粘性 | 宽度大、熵看似稳定 | AV 退火和最终 AV 上限；强制报告 \(\mu_{art}\) |
| 组件过多、创新像“拼盘” | 消融无法给出主导机制 | 论文主贡献聚焦“显式流形 + 分布约束”，其余为训练支撑 |
| WENO 单次求解全面占优 | neural wall-clock 无竞争力 | 明确定位参数化多查询、反演或可微设计，不虚报替代传统 CFD |

## 12. 建议实施顺序

1. 实现统一 WENO/精确 Riemann 参考与指标库；
2. 复现 MLP、AV、PINNs-WE 与原 DPINN 的 Burgers/Sod；
3. 在原 DPINN 上先加控制体积守恒和熵损失，形成可工作的 CW-DPINN；
4. 加显式流形和 RH 条件，形成 CSE-DKAN-PINN；
5. 完成 1D 参数扫描、统一预算和消融；
6. 达标后进入 2D 四象限 Riemann，再决定是否投入双马赫反射。

这条顺序把“能复现”“能守恒”“能锐化”“能泛化”分开验证，任何一步失败都能定位原因。
