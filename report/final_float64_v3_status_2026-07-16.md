# DKAN 激波子单元混合模型：float64 十种子最终状态

更新日期：2026-07-16

## 结论

冻结的 `final_1d_float64_v3` 协议通过。允许的强结论是：在协议限定的 1D Burgers 与 Euler Riemann 范围、固定有限体积骨架和统一几何平均指标下，监督式 DKAN 子单元重构混合模型相对固定 MC 子单元基线的跨方程中位增益为 1.4259，十训练种子 bootstrap 95% 置信区间为 [1.3952, 1.4523]，其下界超过 1.20。

这个结论不适用于纯 PINN。直接 CSE-DKAN-PINN 分支仍被局部守恒与熵门否证；成功模型依赖 WENO/精确 Riemann 教师和 Godunov/HLLC 有限体积推进。

## 最终创新结构

### Burgers

1. TVD-Godunov 有限体积法推进严格守恒的单元平均量。
2. DKAN 仅预测离散零均值的子单元修正；五点模板凸缩放保持局部有界。
3. 相对跳跃、最小绝对跳跃和邻域扩张控制间断专家的空间启用。
4. 新增解析黏性厚度门：以 `8*atanh(0.8)*nu/Delta-u` 估计 Burgers 黏性激波 10–90% 厚度；当厚度超过 2 个粗网格单元时，精确回退固定 MC。
5. 训练保存内部验证误差最小的检查点，而不是最后一步；v2 十种子中 8 个最优检查点不在最后一步。
6. 保守凸投影把重构总变差超额限制在 5%。

### Euler

1. HLLC-MUSCL 推进质量、动量与总能量。
2. DKAN 只输出固定守恒 MC 与显式守恒激波基之间的标量混合系数。
3. 0.75 的固定信任域系数抑制训练外过强跳跃修正。
4. 共享凸缩放同时执行守恒分量模板界、密度正性和压力正性。
5. 100/200 单元启用学习重构，400 单元严格回退固定 MC。

## 硬约束审计

- Burgers 最大单元平均变化：`2.22e-16`；最大参考相对 TV 超额：`0.03134`；过冲/欠冲：`0`。
- Euler 最大单元平均变化：`4.44e-16`；最小密度：`0.096668`；最小压力：`0.070945`；激波熵违反：`0`。
- Euler 最大 Rankine–Hugoniot 残差比：`1.1570`，低于 1.20 门槛。
- 高黏度 WENO 参考收敛审计：20/20 通过，最大归一化 L2 差异 `2.9189e-4`，低于 `5e-4`。
- 20 个模型检查点的所有浮点状态张量均为 `torch.float64`。

## 保留的失败证据

- v1：Burgers 最差单对 0.6906，Euler 最差单对 0.9463，跨方程 CI 下界 1.1973；冻结协议失败。
- v2：首个 Burgers 种子已出现 0.8982 与 0.9087 两个失败对，因此按“一对失败即可否决”规则提前停止。
- 这些失败没有从结果目录或协议中删除，也没有并入 v3 成功统计。
